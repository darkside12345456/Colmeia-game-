# Créditos e origem dos ficheiros (secção 11.6)

Regista aqui a origem e a licença de CADA imagem/som que entrar no jogo.

| Ficheiro / grupo | Origem | Licença / uso comercial | Data |
|---|---|---|---|
| Abelhas, blocos, ícones, botões, fundos (src/art/*) | Desenhados por código para este jogo | Original - pertence ao projeto | 2026-10 |
| Pixel art dos níveis (assets/levels/art/*.png) | Gerada por `npm run art` a partir de tools/art/motifs.ts | Original - pertence ao projeto | 2026-10 |
| Sons e música (src/services/audio.ts) | Sintetizados por código (Web Audio) | Original - pertence ao projeto | 2026-10 |
| Ícone da app, splash, imagem de destaque (store/, android/res) | Gerados por `node tools/make-icons.mjs` | Original - pertence ao projeto | 2026-10 |
| Letras Baloo 2 e Nunito | Google Fonts via @fontsource | SIL OFL 1.1 (uso comercial permitido) | 2026-10 |

Quando trocares algo por um ficheiro de um ilustrador, de IA ou de uma loja de assets:
1. Confirma que os termos permitem uso comercial (nada de "uso não comercial").
2. Guarda o recibo/licença.
3. Acrescenta uma linha a esta tabela.
